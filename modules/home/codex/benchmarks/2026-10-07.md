# Matched Codex model benchmark — 2026-10-07

This initial calibration supports Luna/high for well-bounded coding and focused
lookup, and Sol 6.1/medium for Nix activation/module wiring and Nix/store/USB
contracts. It does not establish universal model quality or a subscription
allowance multiplier. Main coding stays Sol/medium; Plan mode stays extra high.

## Results

Each row is one assignment, including at most one same-model repair within a
combined ten-minute limit. Acceptance includes independent checks and material
review findings. No model upgrades or discarded coding attempts were allowed.

Both Go pairs passed without material review findings. Luna's candidate-turn
credits were approximately 8.4 times lower for email login and 21 times lower for
the pooled test. Sol used fewer raw tokens, so token totals alone would give a
misleading cost comparison. Cache ratios also differed substantially.

Both Nix candidates initially added an unregistered check and needed one repair.
Luna's repaired files installed correctly, but an actual Home Manager dry-run
failed on a fresh home and created six temporary files in an existing home.
Sol's dry-run remained inert. Luna's shell implementation initially used an
unsupported Nix flag and invented JSON envelope. Its repair passed the independent
runtime oracle but timed out with incompatible test fixtures still failing.

Several native sessions had workspace-routing/network retries; one switched from
WebSockets to HTTPS after five retries. These delays count against the limit, but
timeouts are incomplete, infrastructure-confounded observations rather than clean
model capability failures. They still prevent accepting those results.

## Native usage and accounting

Input includes cached input; output includes reasoning output when present.
Completed `turn.completed` usage is counted once per turn. Repair turns are added
once; cumulative intermediate snapshots are not summed. Missing completed-turn
usage remains unknown, including the unfinished Luna Python and shell attempts.

lower bound, not its full assignment cost.

Standard credit estimates use
`((input - cached) * input_rate + cached * cache_rate + output * output_rate) / 1_000_000`. Rates were Luna 2.5/0.25/12.5
and Sol 50/2.5/250 for uncached/cached/output. See the [Codex pricing reference](https://learn.chatgpt.com/docs/pricing#token-rates).
These are a comparison proxy, not measured account billing or an exact ratio of
included subscription usage. Shared preparation, coordination and independent
review usage were not allocated to individual rows; full accepted-result cost
therefore remains unknown. Review and repair must remain part of production work.

## Protocol and acceptance

Ten primary assignments, thirteen native invocations including three repairs.
Pinned Codex 0.160.0; explicit Luna/high or Sol 6.1/medium;
`service_tier="default"` for Standard; workspace-write/on-request; no delegation
inside candidates; user configuration ignored and Clef disabled. Each candidate
used the same brief and reference-parent snapshot as its matched partner, with
history removed. Reference solutions and future commits were withheld by layout
and instruction, not filesystem read confinement; no reference access was observed.
Active source worktrees were untouched. Dependencies were prepared once.

Reference commits:

- Forum email: `40a0d125bedc27eac76d5d3302e92d9e7a69e9c5`.
- Forum pooled test: `e06110e50756d8161db374b7b9b99226233457ed`.
- Python session cap: `7e7c83f4382dc5f5213b5e04f61cfe8249493dfd`.
- Nix agent files: `5d45e4305e2aa50d6c633f05b129041230480628`.
- Shell staging: `dc34c338400efa2a3721fcdef210a77d806bee2e`.

Acceptance verified email-only login/errors/template behavior; simultaneous
reservation of two Go database connections and rejection of an initial-connection-
only foreign-key mutation; nullable and finite Python caps, retained counters and
UTC daily reset; real isolated Nix activation/migration/private modes/O_NOFOLLOW,
registry integration and inert dry-run; shell desired/rollback union, missing
download bytes, capacity boundaries and actual Nix flag/JSON/read-only contracts.
Original baselines failed target checks, references passed, and deliberate broken
fixtures were rejected. Semantic alternatives were accepted; exact reporting
wording and fragile historical mock option ordering were supplemental evidence.
No full historical host closures or real USB writes were needed.

One sample per model/case, fixed order, shared caches and variable network retries
limit conclusions. Raw prompts, outputs, diffs, controls and JSON reports remain
in the local `/tmp/codex-efficiency-benchmark/{go,config}` artifact directories;
they are temporary and were not uploaded to Clef or committed as production code.
